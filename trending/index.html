GitHub Trending

I snapshot the official GitHub Trending charts every week and keep them in this repo. The weekly chart shows now — the monthly one shows what actually held attention.

The chart is captured every Sunday night. Once enough snapshots pile up, monthly and yearly rankings appear here.

Method: both the weekly and monthly charts come straight from GitHub’s official Trending pages (since=weekly / since=monthly); numbers are never edited. Weekly snapshots run Sunday 22:00 UTC+8 and cover Monday to Sunday. Monthly snapshots run on the 1st and cover the previous calendar month. GitHub has no official yearly chart, so the yearly ranking is aggregated from monthly snapshots and computed on this page only.
